# Implementando uma estrutura de dados simples

Neste TAD, Tipo de dado abstrato, vamos criar uma estrutura do tipo numérico
ponto flutuante.

O conteúdo desta variável tem as seguintes regras de negócio:
- Máximo valor permitido = 100; valores maiores que 100 serão convertidos para
100.
- Mínimo valor permitido = 0; valores negativos serão convertidos para 0.
- Não é permitida a faixa compreendida entre valores maiores que 40 e menores
que 60; valores nesta faixa, menores que 50, serão convertidos para 40 e os
maiores ou iguais a 50 serão convertidos para 60.
